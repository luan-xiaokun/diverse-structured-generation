## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| selected baseline certificates → obligation set | Accepted replay evidence determines which catalog structures are missing. |
| reachability prediction → witness selection | Graph evidence may select work but cannot create coverage or success claims. |
| witness search → canonical replay | Generated token IDs cross into the sole acceptance/coverage oracle. |
| internal result populations → JSON/JSONL/terminal | Diagnostics and certificates have different disclosure and integrity rules. |
