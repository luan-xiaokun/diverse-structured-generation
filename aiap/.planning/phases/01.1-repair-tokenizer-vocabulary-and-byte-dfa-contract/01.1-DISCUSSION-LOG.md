| Synthetic token cases | Test every identified boundary case | ✓ |
| CI behavior | Best-effort real-tokenizer check | |
| CI behavior | Strict layered CI with offline locked snapshot | ✓ |

**User's choice:** Require both test layers, exact byte/trace parity, all boundary cases, and strict CI.

**Notes:** Required cases are ASCII, a complete Unicode token, a Unicode code point split across BPE fragments, mixed ASCII/incomplete high bytes in one token, Llama `<0xNN>`, genuine U+FFFD versus a fragment, and zero-byte EOS. The Qwen/CSS job must use `HF_HUB_OFFLINE=1`; missing snapshots fail rather than skip, xfail, or fetch from the network.

The agreed machine outcomes are `success`, `byte_level_unreachable`, `search_limit`, `invalid_witness`, and `internal_error`.
