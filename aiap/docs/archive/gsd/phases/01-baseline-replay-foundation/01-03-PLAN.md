<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| explicit case JSON/source text → CLI | Case schema, source samples, regex, and pinned tokenizer provenance enter the research command. |
| tokenizer encoding/decoding → DFA replay and metrics | Source text becomes token IDs and decoded text before a common trace/metric comparison. |
| CLI candidate flow → JSON/JSONL artifacts | Persisted results may later feed coverage and selection claims. |
| immutable tokenizer lock/provisioner → real-case parity job | Exact external tokenizer material determines production DFA vocabulary construction. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-06 | Tampering | case input/output mapping | medium | mitigate | Require an explicit case path, validate schema/provenance, preserve source/token/decoded values, and resolve paths. |
| T-01-07 | Repudiation | CLI research result | high | mitigate | Write complete JSONL certificates and include accepted/failed counts plus parity diagnostics in summaries. |
| T-01-08 | Tampering | tokenizer-to-replay parity | high | mitigate | Enforce one no-special-token adapter, retain source/decoded text, and block parity after a decoded-text mismatch. |
| T-01-09 | Tampering | metric parity | high | mitigate | Compare parent metrics to independently replayed events/counts per input and expose a categorical discrepancy. |
| T-01-10 | Tampering | tokenizer provenance and provisioning | high | mitigate | Lock `Qwen/Qwen2.5-1.5B-Instruct` to commit `989aa7980e4cf806f80c7fef2b1adb7bc71aa306`, validate it before download, test offline from the provisioned snapshot, and fail rather than skip on an incomplete cache. |
| T-01-SC | Tampering | pip installs | high | accept | No package-manager install is part of this plan; reuse the parent environment. |
</threat_model>
