
1. Raw `bytes` token: `bytes(token)`.
2. `<0xNN>`: `bytes([int(token[3:5], 16)])`.
3. Replacement decode caused by an incomplete GPT-2-style fragment: inverse-map every raw token symbol and call `bytes(values)`.
4. Genuine decoded text, including genuine U+FFFD: `decoded.encode("utf-8")`.
5. Preserve special-token filtering and exclude EOS from the returned ID map.


### Validation boundaries

Preserve catalog order, sort allowed token IDs before graph/BFS iteration, and partition the classified list without reordering it. This makes `--obligation-num` stable.

### Replay authority

**Source:** `aiap/replay.py:108-195`

All success and coverage claims come from `get_next_token_state` plus the exact byte trace returned by `get_byte_transition_sequence_from_state`. Predicted graph reachability is selection evidence only; it cannot create a `success` result.

### Error categorization

Use separate layers:

- constructor contract: `TypeError`;
- artifact machine category: `legacy_artifact`, `unsupported_schema`, `corrupt_artifact`;
- replay detail: `illegal_token`, `byte_trace`, `destination_mismatch`, `non_final`;
- proposal outcome: `success`, `byte_level_unreachable`, `search_limit`, `invalid_witness`, `internal_error`.

Never reuse the removed generic `no_accepting_witness`.

### Artifact self-containment

**Sources:** `../regex_dfa_guide/src/diverse_guide_dfa.rs:20-32,401-408`, `../regex_dfa_guide/src/python_bindings/mod.rs:173-199`

The encoded payload must continue to own the immutable `DfaIndex`, raw vocabulary bytes, token indexes/paths, allowed IDs, and mutable path/local counters. Restore must call no tokenizer APIs and perform no network access.

## Planner Warnings

- Rebuild the extension immediately after Rust/binding edits and before Python verification; otherwise the installed `0.2.0` shared object can mask source changes.
- A generic PyO3 `Vec<u8>` extractor is not strict enough for `dict[int, bytes]`; manual `PyDict`/`PyBytes` validation is part of the contract.
- Check bincode's consumed byte count. A valid payload with trailing bytes is `corrupt_artifact`.
- Reachability must be computed over token actions annotated with byte traces, not the unconstrained byte graph.
- Derive missing obligations from selected baseline replay before classification. Apply `--obligation-num` only after removing unreachable items from the selectable pool.
- JSONL is an attempted-witness artifact, not a dump of all certificates or diagnostics.
