=============================

结论
----
Qwen2.5-1.5B / JSON / DG+ / T=1.3 / seed=44：Vendi 0 → 121.24465296577031。
原始500条样本、顺序、重复字符串、seed和所有生成配置均保留。

根因与证据
----------
原样本索引437（从0开始）含真实NUL字节，不是文本形式的反斜杠转义。
C核把k-mer作为以NUL结束的字符串，通过strlen、strdup和HASH_FIND_STR
存储和查找；这会截断字节子串，并把不同长度的子串混入同一哈希键。
修复用显式k长度的二进制键、malloc/memcpy和HASH_FIND。
原始服务器.so的500×500核矩阵K/n最小特征值为−1.389413e-6；修复后
为−7.818019e-17。包含问题样本及前20条的子矩阵与独立NumPy参考实现的
最大差为3.410605e-13。最小回归输入如['a','a\0','\0a']即可证明旧C与参考核不一致。

评价定义
--------
所有正式重评使用历史已执行参数WD-shift degree=5、shift=1，以UTF-8字节
构造子串；不得改为degree=3或shift=3。旧计算先求K/n特征值，再给每个
特征值加1e-10，传入会再次按总和归一化的scipy.stats.entropy。
因此历史数值实际是原始WD核的trace归一化谱熵，即有效秩。
本次保留这一口径：p_i=lambda_i/sum(lambda)，score=exp(−sum p_i log p_i)。
不引入逐样本单位对角线归一化，不改变长度对核自相似度的权重。
Vendi作者的标准定义要求k(x,x)=1；原始WD核不满足此条件，论文应准确称为
“trace-normalized WD-kernel spectral diversity (Vendi-style effective rank)”
并给出上述公式，避免暗示与单位对角线的标准Vendi完全相同。
来源：https://github.com/vertaix/Vendi-Score （作者说明，2026-10-01查阅）。

去掉人为epsilon，按0 log 0=0计算。仅截断数值误差范围内的负特征值；
容差=128×float64机器epsilon×n×max(abs(eigenvalues))。
明显非PSD、非对称、非有限或零trace矩阵报错，不输出0作为实际多样性。
空样本集合的标量返回0，曲线返回空列表；正式run均为500条，不受此约定影响。
同时修正prefix函数漏掉可整除的最终预算点的问题及CLI图的横轴对应。
本次正式趋势沿用原评估记录中的50、100、…、500样本预算。
